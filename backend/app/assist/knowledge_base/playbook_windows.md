# Windows mitigation playbook
## Windows: apply security updates (patching)
Install the monthly cumulative update that contains the fix: Settings > Windows Update > Check for updates, or in PowerShell (admin) `Install-Module PSWindowsUpdate; Get-WindowsUpdate -Install -AcceptAll`. Check that a KB is installed: `Get-HotFix -Id KB5012345`. Update applications with `winget upgrade --all`. Office, Edge, Exchange and SharePoint have their own updates - patch them too. In companies deploy through WSUS / Intune and reboot; a pending reboot leaves the machine vulnerable.
## Windows: when no patch exists yet (zero-day)
Apply the workaround from the Microsoft advisory (often a registry key, disabling a protocol handler or blocking a file type), turn on Microsoft Defender cloud protection and Attack Surface Reduction rules (block Office child processes, block credential stealing from LSASS), block the affected file types in email, restrict the vulnerable service at the firewall, and remove local administrator rights from daily accounts so an exploit gains less.
## Windows: ransomware and lateral movement
1) Disconnect infected machines from the network (unplug or disable Wi-Fi) but leave them powered on. 2) Disable SMBv1 (`Disable-WindowsOptionalFeature -Online -FeatureName SMB1Protocol`), block SMB (445) and RDP (3389) from the internet, require Network Level Authentication and MFA for RDP. 3) Reset passwords of affected and privileged accounts, reset the krbtgt account twice in Active Directory if domain admin was reached. 4) Turn on Controlled Folder Access. 5) Restore from offline backups after wiping; check nomoreransom.org for a free decryptor; report to CERT-In or local law enforcement. Paying does not guarantee recovery.
## Windows: phishing, malicious documents and infostealers
Block macros from the internet (default in current Office), keep Mark-of-the-Web, enable SmartScreen, and never run scripts from email or chat (.js, .vbs, .lnk, .iso, .hta). If a user opened one: isolate the PC, run a full Microsoft Defender Offline scan, sign the user out of all sessions, change passwords from another device, revoke browser-saved passwords and session tokens (infostealers steal cookies), and enable MFA.
## Windows: detect and investigate
Look at Event Viewer (Security 4624/4625 logons, 4688 process creation, 7045 new service, 4720 new user), scheduled tasks (`schtasks /query /fo LIST /v`), autoruns, PowerShell history, and Defender detections (`Get-MpThreatDetection`). Unknown services, tasks running from AppData or Temp, and logons at odd hours are warning signs.
## Windows: hardening baseline
Automatic updates on; Microsoft Defender real-time and tamper protection on; BitLocker on; standard (non-admin) daily accounts with UAC; LAPS for local admin passwords; firewall on for all profiles; disable unused services (Print Spooler on servers that do not print); MFA for every remote access; regular offline backups.
