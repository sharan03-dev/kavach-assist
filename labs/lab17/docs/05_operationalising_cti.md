# Operationalising threat intelligence in a security operations centre

Intelligence only reduces risk when it changes what defenders do. In a security operations centre, high-confidence indicators are pushed automatically to blocking controls such as firewalls, DNS filters and endpoint protection, while lower-confidence indicators are used only for alert enrichment and threat hunting. A threat intelligence platform aggregates feeds, removes duplicates, scores indicators, applies allowlists and exposes the result to the SIEM and SOAR tools through an API.

Playbooks connect intelligence to response. When an alert matches a known command and control domain, a SOAR playbook can isolate the host, collect forensic data and open a ticket with the related campaign report attached. Threat hunting uses intelligence about actor techniques to search proactively for activity that did not trigger an alert. Vulnerability management uses intelligence about exploitation in the wild, for example the CISA Known Exploited Vulnerabilities catalogue, to patch the flaws attackers actually use first. Metrics close the loop: the number of true detections caused by a feed, the false positive rate per source and the time from publication to blocking show which sources are worth keeping. Retrieval augmented generation can help analysts by answering questions over the organisation's own reports, provided the answers cite their sources.
